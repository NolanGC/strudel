# My Foldkit App

A Foldkit application built with Effect.

## Getting Started

```bash
bun install
bun run dev
```

By default, a fresh clone runs in template mode if `VITE_CONVEX_URL` is absent.
Template mode signs in locally with KeyValueStore-backed auth and uses
in-memory todo backends, so no GitHub OAuth app or Resend key is required.

For real Convex Auth, set `VITE_AUTH_MODE=convex`, configure
`VITE_CONVEX_URL`, and follow [AUTH.md](./AUTH.md).
